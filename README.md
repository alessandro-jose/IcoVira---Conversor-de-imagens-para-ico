# 🎨 IcoVira

Um conversor de imagens para `.ico` simples, rápido e 100% online. Toda a conversão é feita localmente no seu próprio navegador, sem enviar seus arquivos para nenhum servidor.

🔗 **Acesse o site aqui:** <a href="https://alessandro-jose.github.io/icovira-conversor-de-imagens-para-ico/">https://alessandro-jose.github.io/icovira-conversor-de-imagens-para-ico/</a>

---

## ✨ Funcionalidades

* **100% Local no Navegador:** Suas imagens são processadas direto no seu computador. Privacidade total e conversão instantânea.
* **Vários formatos aceitos:** Suporta PNG, JPG, JPEG, SVG, WEBP, entre outros.
* **Direto ao ponto:** Sem cadastros, sem instalação e sem limites de uso.

---

## 🚀 Como usar

1. Acesse o link do site no GitHub Pages.
2. Selecione ou arraste a imagem que deseja converter.
3. Clique para converter e baixe o seu arquivo `.ico` pronto.
